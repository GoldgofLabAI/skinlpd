# Attention Post-Processing Pipeline

This document describes the `postprocess_attention.py` script, which combines MIL (Multiple Instance Learning) tile-level attention with UNI encoder token-level attention to produce granular, sub-tile attention maps for whole slide images.

## Overview

The standard MIL attention from `compute_attention.py` provides attention weights at the **tile level** (one weight per 256×256 tile). This post-processing script enhances that by:

1. Loading MIL tile-level attention weights
2. Computing UNI encoder token-level attention (14×14 grid per tile) on-the-fly
3. Combining them to produce **sub-tile granularity** attention maps
4. Saving organized H5 files with the combined attention
5. Generating thumbnail visualizations with heatmap overlays


## Usage

### Basic Usage

```bash
python postprocess_attention.py \
    --mil_attention_dir /path/to/mil_attention_h5 \
    --csv_path /path/to/slides.csv \
    --thumbnail_dir /path/to/thumbnails \
    --output_dir /path/to/output
```

### Full Options

```bash
python postprocess_attention.py \
    --mil_attention_dir /path/to/mil_attention_h5 \
    --csv_path /path/to/slides.csv \
    --thumbnail_dir /path/to/thumbnails \
    --output_dir /path/to/output \
    --visualization_dir /path/to/visualizations \
    --device cuda:0 \
    --batch_size 256 \
    --alpha 0.5 \
    --skip_existing \
    --skip_visualization
```

## Command Line Arguments

| Argument | Required | Default | Description |
|----------|----------|---------|-------------|
| `--mil_attention_dir` | Yes | - | Directory containing MIL attention H5 files from `compute_attention.py` |
| `--csv_path` | Yes | - | CSV file with `sl_filepath` (WSI paths) and `slide_name` (base + .svs) columns |
| `--thumbnail_dir` | Yes | - | Directory containing thumbnail images (JPG format, named `{slide_name}.jpg`) |
| `--output_dir` | Yes | - | Output directory for combined attention H5 files |
| `--visualization_dir` | No | `{output_dir}/visualizations` | Directory for thumbnail visualization PNGs |

| `--alpha` | No | `0.5` | Transparency for visualization overlay (0-1) |
| `--tile_size` | No | `256` | Fallback tile size if `patch_size_level0` not in H5 |
| `--skip_existing` | No | False | Skip slides that already have output files |
| `--skip_visualization` | No | False | Skip generating visualizations |

## Input Requirements

### 1. MIL Attention H5 Files

Generated by `compute_attention.py`. Each file should contain:

- `/coords` - (N, 2) tile coordinates at level 0
- `/attention` or `/attention_normalized` - (N,) attention weights
- Coords attributes: `patch_size_level0`, `target_magnification` (optional but recommended)

### 2. CSV File

Must contain these columns:

- `sl_filepath` - Full path to the WSI slide file
- `slide_name` - Slide name with `.svs` extension (e.g., `slide123.svs`)

The slide base name (without `.svs`) is used to match with MIL H5 files.

### 3. Thumbnail Images

- Format: JPEG
- Naming: `{slide_name}.jpg` (e.g., `slide123.jpg`)
- Can be generated using trident's visualization or other tools

## Output H5 Structure

Each output file `{slide_name}.h5` contains:

```
/coords                 - (N, 2) tile coordinates at level 0
/combined_attention     - (N, 14, 14) combined attention maps per tile

Attributes:
  - slide_name: str
  - num_tiles: int
  - mil_attention_path: str
  - processing_timestamp: str (ISO format)
  - tile_size: int (patch footprint at level 0)
  - token_grid_size: int (always 14)
```

## Magnification Handling (20x vs 40x)

The script automatically handles slides with different native magnifications:

### How It Works

The `patch_size_level0` attribute stored in the MIL attention H5 file indicates the actual footprint of each patch at level 0 (native resolution):

| Native Magnification | Target Magnification | patch_size_level0 |
|---------------------|---------------------|-------------------|
| 20x | 20x | 256 |
| 40x | 20x | 512 |

### Processing Differences

**For 20x slides:**
- Patches are read as 256×256 at level 0
- Resized to 224×224 for UNI input
- Visualization places tiles with 256px spacing

**For 40x slides:**
- Patches are read as 512×512 at level 0
- Resized to 224×224 for UNI input (downsamples to match 20x)
- Visualization places tiles with 512px spacing

This ensures the attention heatmap correctly aligns with the tissue regions regardless of the slide's native magnification.

## UNI Attention Extraction

The script extracts attention from the UNI encoder (ViT-Large) using forward hooks:

1. **Hook Location**: Last transformer block (layer 23) attention module
2. **Attention Type**: CLS token attention to patch tokens
3. **Head Aggregation**: Mean across all 16 attention heads
4. **Output Shape**: 14×14 per tile (196 patch tokens from 224/16 = 14)

### Technical Details

```python
# The hook captures attention during forward pass
# attn shape: (batch, num_heads, seq_len, seq_len)
# We extract: attn[:, :, 0, 1:]  # CLS to patches
# Then average across heads and reshape to 14×14
```

## Attention Combination Formula

For each tile `i`:

```
combined_attention[i] = MIL_attention[i] × normalize(UNI_attention[i])
```

Where `normalize()` applies min-max normalization to [0, 1] range.

This weighting ensures:
- Tiles with low MIL attention contribute less overall
- Within high-attention tiles, UNI attention highlights important sub-regions
- The result is a hierarchical importance map

## Visualization Output

The visualization creates a side-by-side comparison:

1. **Left panel**: Original thumbnail with tissue region bounds (cyan dashed box)
2. **Right panel**: Attention heatmap overlay using the 'hot' colormap

The heatmap is generated by:
1. Upsampling each tile's 14×14 combined attention to thumbnail resolution
2. Placing tiles at correct positions based on coordinates and scale
3. Normalizing the full attention map
4. Blending with thumbnail using configurable alpha

## Troubleshooting

### "Slide not found in CSV mapping"

Ensure the slide base name (H5 filename without `.h5`) matches the `slide_name` column in CSV (without `.svs`).

### Grid pattern in visualization instead of continuous heatmap

This indicates the `patch_size_level0` attribute is missing or incorrect. Check that:
1. The MIL attention H5 files were generated from feature H5 files that include this attribute
2. The original feature extraction used proper magnification handling

### HuggingFace authentication errors

Set your HuggingFace token in environment or `.env` file:
```
HUGGINGFACE_HUB_TOKEN=your_token_here
```

### Out of memory errors

Reduce `--batch_size` (default 256) to a smaller value like 64 or 128.
